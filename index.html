주소 엑셀 → 지도

엑셀(.xlsx/.xls/.csv)을 올리면 주소를 좌표로 바꿔 지도에 점으로 찍습니다.

1 Google Maps API 키
키가 없다면
  1. Google Cloud Console에서 프로젝트 생성
  2. API 및 서비스 → 라이브러리에서 Maps JavaScript API와 Geocoding API 두 개를 사용 설정
  3. 사용자 인증 정보 → API 키 만들기 → 키 복사
  4. 결제 계정 연결 필요(매월 무료 크레딧 제공)

키 제한을 걸 경우 HTTP 리퍼러에 http://localhost:* 를 허용하고, API 제한에는 위 두 API를 모두 포함하세요.

매번 입력하기 번거로우면 config.example.js를 config.js로 복사해 키를 적어두세요. 파일이 있으면 자동으로 불러옵니다.
